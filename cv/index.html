What changed between the two cycles

The 2024 Microsoft 365 Copilot programme reached company-wide use with varying integration levels, including full technical-team adoption. The tooling’s usefulness was limited. The later programme added an eight-person evaluation, side-by-side vendor comparison, a cost model, a governed adoption decision and production automation across engineering, Professional Services and customer-facing workflows.

Three manual questions closed into one loop

An MCP server joined a configuration-monitoring product to an enterprise change-management system: was this the intended change, did anything unexpected arrive, and does the result meet policy?

Advisory operation and bounded writes

Advisory, never autonomous. Write actions were off by default. The harness combined restricted-role credentials, human confirmation and a preview-to-apply token. The interactive console is a local illustration of those checks, not access to an enterprise system.

Failure that remains intelligible

A lost network path stopped failing silently and instead exposed four explicit degraded-but-alive states. The four modes here illustrate the principle; they are not the production state names.

Policy must come from the scan

Invented content was an acceptance criterion with a pass mark. Every generated path was checked against the scan; absent subjects were omitted rather than invented. Use the present/absent controls to inspect that distinction.

Blockers and unusual compatibility constraints

Resolved a four-month client blocker alongside development teams. Investigated 16-bit compatibility through hands-on workarounds for environments mapped to physical machines, test beds and robotics. The approach informed later product capability.

Earlier results from hands-on investigation

At Aspen Insurance, resolved BIOS-level issues that saved the business around £250k and halved iPhone setup times. Earlier service-desk work included 200+ knowledge base articles for repeatable resolution across global offices.

Generate, apply, then judge independently

A lab generates an editorial comment, applies it with a second model and scores draft and revision against a rubric using a held-out judge. An add-in inserts a comment only after the same acceptance check. Built over a weekend; repository private.

Validate the judge first

Judges were validated against a hand-labelled golden set using Cohen’s kappa before their scores were trusted. The six cases on this board are a separate illustrative dataset, not the research results.

What the harness surfaced

Models fabricated supporting evidence under pressure. Cheaper judges matched or beat frontier models on the task and held steadier across repeats. No particular model, score or benchmark result is invented here.

Canada · recovering a stalled migration

Five weeks on-site on a stalled Windows Server 2022 migration: completed development and pre-production, then bridged the UK and Canadian teams across time zones into production.

Packaging without manual intervention

Led the design of an unattended AWS server-workload packaging pipeline with input from the AWS solutions architect and head of engineering. The team built it under technical management, removing manual packaging effort from migrations.

Access is scoped

WorkOS authentication verifies JWTs against AuthKit JWKS with read and write scopes. Sharing one dataset does not mean every caller has the same authority.

Migrations and deployment have owners

Single-owner database migrations and a deploy token scoped never to run on pull requests. Two Workers serve the app and MCP interface over shared D1 storage.

What the sample represents

A React web app, CLI and custom MCP server reach the same training dataset. The cables illustrate request and return paths through the services; the animation is not a claim of live push synchronisation. Sign-ups remain closed; the site is public and the repository private.

The port retains its reference

A line-for-line Kotlin port keeps the Python scoring engine alongside as a reference check. The comparison here uses small illustrative output vectors; it does not run either engine.

Checks reach the delivery artifact

95 unit tests; every merge builds a signed APK. Silero voice activity detection is bundled as ONNX in the APK. The Android app is still in build and not released.

Exactly what was demonstrated

The native-agent shape was proved on aarch64 for the CGO-free subset of collectors. That stops short of full configuration coverage.

Accepted evidence is not a release

Presented the evidence case to engineering; it was accepted and build-pipeline and publish work was raised. The implementation remains unmerged pending engineering delivery. The platform proof model illustrates this recorded status; it does not compile or run the agent.

An operating model for experiments

Designed the intake-to-graduation lifecycle, the skills matrix for assigning specialists, and Slack-to-Jira intake with AI-assisted triage. The work item and skills pairing here are illustrative; they do not disclose an internal backlog or team roster.

Parallel work with verified outputs

Each of roughly 29 parallel build streams had its own branch, worktree and written brief. Verified commit hashes provided a checkable trail before integration.

Know when to stop iterating

The prompt reached v2.2 through a 40-check evaluation harness and a 14-sentence live battery, then was frozen as a priced decision. The preserved hackathon build remains public.

Recognition at Ready, Spec, Ship

Built for the Kiro-sponsored hackathon and received an honourable mention. Gregor Ojstersek called it unconventional and explored the different options to test it; John Crickett recognised the StumbleUpon inspiration.

A public specification trail

Seven specifications, agent hooks and human gates at every step. The repository and full specification trail are public.

Ranking with checks attached

404 tests across 27 files, including property-based checks on the ranking engine, against a 349-row curated independent-web corpus. The receiver’s example cards are illustrative, not live ranking results.

A small runtime footprint

React and Hono on one Cloudflare Worker over D1; three runtime dependencies and no runtime secrets.
